# aijsondbjweb

A demonstration of how to create an AI Agent with **aijsondb**.

This is a **Spring Boot** web application that allows you to upload Excel files and query their contents using natural language.

## Features

- Upload XLSX (Excel) files
- Ask questions about the data in natural language
- Get accurate answers from your spreadsheet data

## Installation & Setup

### Prerequisites

- Install [JBang](https://jbang.dev/) - a Java-based script runner

### API Configuration

Configure your AI provider by setting the appropriate environment variables:

| Provider | Environment Variable | Description |
|----------|---------------------|-------------|
| Mistral AI | `MISTRAL_API_KEY` | Your Mistral AI API key |
| OpenAI | `OPENAI_API_KEY` | Your OpenAI API key |
| Ollama | `OLLAMA_URL` | Custom Ollama URL (default: `http://localhost:11434`) |

### Running the Application

```bash
jbang aijsondbjweb@awenzel67
```

Then open your browser to: [http://localhost:11434](http://localhost:11434)

## Usage

1. Start the application using the command above
2. Open your browser to `http://localhost:11434`
3. Upload an Excel (.xlsx) file containing your data
4. Enter questions in natural language about the data
5. Receive answers generated by the AI agent

## Technology Stack

- **Spring Boot** - Java web framework
- **aijsondb** - JavaScript database query engine
- **langchain4j** - Java ai agent framework
- **JBang** - Java script execution

## Supported AI Providers

- ✅ Mistral AI
- ✅ OpenAI
- ✅ Ollama (local)
