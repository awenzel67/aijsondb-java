aijsondbjweb is a demonstration how to create a AI Agent with aijsondb.

It is a spring boot web application.

Functionality:

Upload a xlsx (Excel) file.
You can than enter questions on the data in the xlsx (Excel) File in natural language and get answers.

Installation:

install jbang 

if used with MistralAI save API key in environmentvariable: MISTRAL_API_KEY

if used with OpenAI save API key in environmentvariable: OPENAI_API_KEY

if used with Ollama: default URL is: http://localhost:11434. Using an other URL save it in environmentvariable: OLLAMA_URL

enter in console: jbang aijsondbjweb@awenzel67

open in browser: hhtp://localhost:11434
